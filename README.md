## Selected Projects

### CPA GrowthOS: AI inbox and meeting analysis backend
Backend for an AI inbox with Gmail and Outlook OAuth flows. Drafts replies in each user's own writing style using Pinecone vector search. Includes meeting analysis APIs built on Recall.ai and a calendar sync service.

### LeadsFlow AI: lead generation and outreach platform
Sources and enriches B2B leads through Apify and the Apollo API, stores them in Supabase, and runs personalized email outreach with reply tracking over the Gmail API. Includes a Next.js dashboard for lists, campaigns, and responses.

### Skip tracing system for a US debt recovery agency
Pipeline that finds and verifies debtor contact details using Apify and GPT-4.1, with a Retell AI voice agent placing calls. Supabase as the data store and a Next.js app serving separate staff and client portals. Also scoped and designed a business identity confirmation stage as a follow-on phase.

### AuthR Protocol demonstration
Backend with Ed25519 request signing and an interactive Next.js playground, built as a demonstration for Identient Corp.

### Image forgery detection
Transfer learning model using EfficientNet and ResNet, trained on the CASIA v2.0 dataset.
